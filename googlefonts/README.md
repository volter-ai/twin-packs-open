# Google Fonts

Google Fonts exposes a Developer API catalog, browser-selected CSS stylesheets
and the font-file URLs those stylesheets name. This Protocol 3 package follows
google-webfonts-helper's pinned production call chain and the CSS2 calls of Dub's
and Rallly's Open Graph images, with scoped host rules
and a World-issued GOOGLE_FONTS_API_KEY. The application stays unchanged.

Each lane's spec/SOURCE.md owns the vendor contract. vendor/SOURCE.md attributes
the selected Antic reference catalog, Inter's CSS2 weights and genuine font files;
vendor/OFL.txt and vendor/Inter-OFL.txt are their licenses. The seed imports this snapshot through the publisher door,
because the read-only Developer API has no font-creation operation. The World
records items and blob bytes, rather than fabricating a stored API mutation.

For the operating model and pack procedure, see twin-world's
docs/contributing/architecture.md and docs/guides/use-with-a-coding-agent.md.
