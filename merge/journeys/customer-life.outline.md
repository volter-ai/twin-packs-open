# Merge Gateway: the customer life, outline

The Open Autonomy operator creates a Pro organization on 1 September 2026, before Anthropic's access cutoff,
buys its credit and saves the Gateway key. On 1 October the team rolls out ledger workers for RH2, Harness and
Substrate. Gateway supplies scripted turns or labeled stubs; the life checks routing, protocol and accounting,
without claiming that a model implements the application work.

1. **Choose the worker model.** The picker pages `models_list` with the returned cursor, then Hermes sends a
   `chatCompletions_create` question and the operator requests the ledger summary for review.
2. **Reconcile and compare.** A provider outage refuses reconciliation with 503. The job backs off for an hour
   and retries after recovery. Hermes asks for the operating balance against the captured ledger summary; the
   application returns the tool result, and a scripted final reply states the 10 USD balance and that transaction
   amounts are missing, so the ledger cannot yet be reconciled. This is a scripted accounting review outcome.
   The operator asks for next tasks with routing costs.
3. **Review the retry change.** A native Responses adapter, without a Codex originator or OpenAI wire-format header,
   sends `responses_create` for an explanation, then requests a streamed retry-function draft. An Anthropic-wire
   reviewer uses `messages_create` to request the file list; the application returns its captured tool result and
   receives a streamed continuation with routing metadata. These continuations use labeled stubs and prove the
   wire and tool-result flow.
4. **Repair a deployment binding.** The next day a worker deployment loses its key and receives 401. Restoring the
   same captured key via X-API-Key lets it request the summary. This is a configuration repair, not a retry with the
   unchanged missing credential.
5. **Onboard Editor.** A separate organization is made through `door:organizations` after the cutoff. Its model picker
   lists Anthropic as access-required. Pi's first streamed bevel-plan request receives 403. Support's grant through
   `door:access` lets Pi retry. The original pre-cutoff operator can use the same model without a support grant.

Malformed model selection, invalid keys, over-large pages and exhausted credit are documentation examples in the
separate examples journey, rather than errors invented as activities for this operator. The three model surfaces,
model listing and both World doors reach every operation in the demand and decision table.
