# Tavily API sources

`openapi.json` is the retained merge of Tavily's published per-endpoint OpenAPI 3.0.3 documents, API version 1.0.0, read on 2026-09-30. Each operation's `externalDocs` names its upstream document under `https://docs.tavily.com/documentation/api-reference/endpoint/`: search.md, extract.md, crawl.md, map.md, research.md, research-get.md, feedback.md, usage.md and logs.md. The documents are published as the YAML blocks on those pages, not as a versioned source repository; no upstream Git commit is published. The merge adds those source links and combines their paths/components.
