# @volter/twin-cerebras

Protocol 3 twin of the Cerebras Cloud API. Nothing is served: neither demand
record names Cerebras among the 18 scanned applications, and no platform or
other-pack runtime caller adds an operation. Every spec operation is unmodeled.
There are no handlers, resources, credential doors, model scenarios or refresh.
The kernel retains its standard discovery and World doors.

Unserved operations and unknown paths answer the documented not-found class
(404) in the spec's error envelope. The documentation does not fix literal
URL-refusal text or an error code; the gap says `Not found` without inventing
one. Bearer authentication is declared for the vendor wire.

The life is empty. Published spec examples are unchanged and counted as
examples of unserved operations. `spec/SOURCE.md` records the unchanged
upstream document, its provenance, version and hashes.
